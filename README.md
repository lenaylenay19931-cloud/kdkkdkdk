# Diagnóstico Aéreo de Cultivos (Mandarina, Caña de Azúcar, Zarzamora)

Este repositorio contiene la plataforma web interactiva **AgroScan Pro** para el diagnóstico espectral de cultivos mediante imágenes de dron (NDVI, NDRE y VARI).

## Despliegue en GitHub Pages:
1. Sube estos archivos a tu repositorio en GitHub.
2. Ve a **Settings -> Pages**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Guardar. Tu aplicación estará en línea en un par de minutos.
